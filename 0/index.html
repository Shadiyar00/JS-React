1. Variables and Data Types

Explanation

JavaScript has different data types. Primitive values include string, number, boolean, null, undefined, bigint and symbol. Objects and arrays are reference values.

let can be reassigned, while const cannot be reassigned.

typeof null returns "object". This is a historical JavaScript behavior.

2. Arrays

Explanation

map() creates a new array with changed values. filter() selects values. find() returns the first matching value. reduce() combines values into one result. includes() checks if a value exists.

3. Arrays of Objects

Explanation

Arrays can contain objects. We can use map(), filter(), find() and reduce() to work with this data.

4. Objects

Explanation

Objects store data using key-value pairs. Destructuring allows us to get values from objects easily.

5. Values and References

Explanation

Objects are reference values. If two variables point to the same object, changing one variable can affect the other. The spread operator creates a shallow copy.

6. Functions

Explanation

Functions allow us to reuse code. They can receive parameters and return results.

7. Functions as Values

Explanation

Functions are values in JavaScript. They can be stored in variables and passed to other functions.

8. Scope

Explanation

Scope determines where a variable can be accessed. JavaScript has global, function and block scope.

9. Closure

Explanation

A closure allows an inner function to remember variables from its outer function even after the outer function has finished.

10. Destructuring, Spread and Rest

Explanation

Destructuring extracts values. Spread expands an array or object. Rest collects multiple values into one array.

11. Optional Chaining and Default Values

Explanation

Optional chaining ?. prevents errors when a property does not exist. Nullish coalescing ?? provides a default value when the value is null or undefined.
