# Guild Quest Board

React (Vite) dashboard for managing fantasy quests. Uses only functional components and `useState`.

## Run locally
    npm install
    npm run dev

## Deploy to GitHub Pages
1. Create a GitHub repo and push this project to it.
2. `npm run deploy` (builds and pushes `dist` to the `gh-pages` branch).
3. Repo Settings → Pages → Source: branch `gh-pages`, folder `/ (root)`.
4. The app is live at `https://<your-username>.github.io/<repo-name>/`.
